# 목표·통계 계약과 데이터 보존

## 기간

- 새 UI는 Asia/Seoul의 현재 연도/월을 명시적으로 전송한다.
- `GET /api/goal/goal/?year=YYYY`는 그 연도의 **연간 목표**만 반환한다.
- `?year=YYYY&month=M`은 정확히 해당 **월간 목표**만 반환한다.
- `progress/`와 `monthly-progress/`에도 같은 기간 필터가 적용된다.
- 목표가 없어도 명시 기간 진행률은 `goal_id: null`, `goal_books: 0`으로,
  월별 통계는 누락 월을 0으로 채워 반환한다. 연도 조회는 12개 월,
  월 조회는 해당 월 하나를 반환한다.
- `goal_period`는 선택된 목표의 원래 기간, 응답의 `year/month/scope`는
  집계 기간이다. 무기간 목표를 올해 목표로 재해석하지 않는다.

## 쓰기·소유권

- `total_books`는 1~2147483647 정수. `read_books`는 read-only 동적 값이다.
- POST 본문으로 `year`/`month`를 명시한다. POST query로 기간을 지정하면
  생략된 본문 기간을 채우고, 본문과 query가 다르면 400이다.
- 연간 목표는 `year` 지정 + `month: null`; 월간 목표는 둘 다 지정한다.
- year는 1~9999, month는 1~12. year 없는 month는 400이다.
- 기간별 중복은 사용자별 API 검증과 조건부 DB 유일성 제약으로 막는다.
- user는 인증 사용자로 지정한다. 타인의 조회·수정·삭제는 404이다.
- 기존 목표의 year/month를 바꿔 이동할 수 없다. 새 행을 만들어야 한다.
- 저장은 목표 권 수만 수정하며, 리뷰 생성/수정/삭제가 저장 counter를 바꾸지 않는다.

## 무쿼리 호환·보존

- 무쿼리 목록은 모든 기존 목표를 반환한다. 잘못된/0/음수/중복 legacy 목표도
  권 수 원본 그대로 남아 수동 확인이 가능하다.
- 기간 없는 POST는 무기간 목표를 만든다. 자동 현재연도 할당은 없다.
- 무쿼리 progress는 기존처럼 첫 목표와 전체 기간의 고유 리뷰 도서 수를
  사용하며 목표가 없으면 404다. 무쿼리 monthly-progress는 현재 서울 연도
  통계를 제공한다. 목표가 없어도 통계를 표시하기 위해 이 endpoint의
  기존 목표 없음 404는 의도적으로 200/0으로 확장했다.
- 무쿼리 통계의 첫 목표가 무기간이거나 다른 기간이면 `goal_period`와
  집계 기간을 구별한다. 새 UI는 이러한 호환 모드를 사용하지 않는다.
- migration 0003은 nullable year/month를 추가하며 backfill하지 않는다.
  0004는 명시 기간 행에만 적용되는 조건부 unique 제약을 추가한다.
  기존 legacy 값/행을 수정·삭제·정리하는 data migration은 없다.
- 원본 DB에는 migration을 실행하지 않았다. 배포/원본 적용은 별도 승인 사항이다.

## 날짜 의미·승인 경계

`date_basis: REVIEW_RECORD_DATE`, `date_field: review.created_at`은 **리뷰 기록일**이다.
월 경계 및 집계 timezone은 Asia/Seoul이다. 이는 실제 완독일, 완독 이벤트,
책을 읽은 시점, 현재 완독 상태를 증명하지 않는다. 리뷰 날짜를 실제 완독일로
자동 변환하거나 과거 기록에 완료일을 채우지 않는다. 실제 완독 이벤트와
재독/취소/이동 정책은 별도 승인과 모델/API 작업이 필요하다.
